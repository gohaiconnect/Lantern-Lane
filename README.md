# Lantern Lane

Slide a glowing celestial lantern across deep space to catch falling gold lanterns, dodge purple void lanterns, clear rhythmic levels, and unlock powered lantern colors in the shop.

## Play Online

Once deployed via GitHub Pages, play at: https://gohaiconnect.github.io/Lantern-Lane/

## Local Development

```bash
npm install --legacy-peer-deps
npm run dev
```
